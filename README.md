# Today — 大人のリアル攻略本

問いから始まり、歴史上の失敗、人類の修正、現代への転移をたどって、最後に日常語へ圧縮された知恵へ着地するデジタル絵本プロトタイプです。

## 現在の実装

- Section 01: 「なんで子どもの頃の1年って、あんなに長かったんだろう？」
- 本型UI
- 左スワイプで次ページ / 右スワイプで前ページ
- 右下のページ角からもページ送り
- Section内の「失敗 → 人類が気づく → システムをガチガチに組む」をサビとして強調
- デイの簡易SVGマスコット
- ブラウザ内に進捗保存
- 第1冊100セクション完読までは本棚をロックする前提設計

## セクション追加方法

`sections.js` の `GUIDE_DATA.volumes[0].sections` に新しい section オブジェクトを追加します。

制作用の `sources` はUIには表示されません。読者向け本文には「研究によると」「○○という理論」などを原則出さず、裏取りにだけ使う設計です。

`window.SECTION_TEMPLATE` に追加用の雛形があります。

## ファイル

- `index.html` — アプリの入口
- `styles.css` — 本・紙・サビ・ページめくり・デイの見た目
- `app.js` — 読書UI、スワイプ、進捗、セクション遷移
- `sections.js` — コンテンツデータ。今後の追加は基本ここだけ
